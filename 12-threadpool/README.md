# 动态线程池

固定 3 个 worker 打底，加一个巡检线程按负载扩缩容，参照课程实现。

## 编译运行

```bash
make
./test 60 2      # 60 个任务，每个 2 秒
./test 100 1     # 100 个任务，每个 1 秒
```

第一个参数任务数，第二个参数单任务耗时（秒），不传默认 60 / 2。

## 记一下

- 队列空/满都挂条件变量上等，不轮询。
- 两把锁：`pool->lock` 管队列和线程名册，`thread_counter` 单独管 `busy_thr_num`，避免统计忙碌数时和入队抢同一把锁。
- `threads[]` 当槽位池用：worker 退出把自己的槽位置 0，扩容找 0 的位置复用。不然反复扩缩会把名册耗光。
- 巡检 10 秒一次：积压超过 10 个扩容，空闲超过忙碌两倍缩容，单次最多动 10 个。
- destroy 遍历名册要用 `max_thr_num`（容量），不能用 `live_thr_num`（人数）——按人数扫前 N 格会漏掉排在后面的活线程，`free` 之后就是 use-after-free。空槽要跳过。

跑 `./test 60 2` 能看到 live 从 3 涨到 13 再落回 3。
