# TCP 客户端

从标准输入读一行发给服务器，接收回显并打印。

## 编译运行

```bash
make
./client                       # 默认 127.0.0.1:8000
./client 192.168.1.10 9000     # 指定地址和端口
```

输入内容回车发送，Ctrl+D 结束。

## 说明

配合 `04-epoll-server` 和 `02-epoll-reactor` 使用，用于验证服务器的连接、回显和断开处理。

- `connect` 失败直接退出，不做重试
- 发送用 `send`，接收用 `recv`，`recv` 返回 0 表示对端已关闭
- 收到数据按字节数 `write` 到标准输出，不假定数据以 `\0` 结尾
